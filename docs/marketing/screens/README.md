# Sample product screens (design-partner reference)

Six core screens captured from the Sona MVP (Flutter web release build against the
live local API), seeded with the canonical synthetic personas
(`scripts/personas/*.json` via `/v1/demo/seed-canonical`). No real patient data.

Compiled into [`../sona-product-screens.pdf`](../sona-product-screens.pdf) for
design/experience conversations. Auth, onboarding and empty states are deliberately
omitted — every screen shows real data.
