# `assets/marketing/` — feedback demo assets

Marketing/sales assets for the May 2026 therapist feedback session.
Built per `docs/marketing/feedback-demo-brief.md`. See
`docs/marketing/README-feedback-demo.md` for the full build log,
decisions and gap list.

## Layout

```
assets/marketing/
├── brand/
│   └── wordmark.svg              # CC0 — built from in-repo design tokens
├── screenshots/
│   ├── ai-mocks/                 # design-fidelity HTML mocks + PNG renders
│   │   ├── prep-brief.{html,png}
│   │   ├── session-plan.{html,png}
│   │   ├── parent-summary.{html,png}
│   │   └── audit-ledger.{html,png}
│   ├── flutter/                  # best-effort Flutter web captures
│   │   └── launcher.png          # CC0 (own work) — pre-login launcher
│   ├── parent-intake/            # reserved for real Playwright captures (gap)
│   └── clinician/                # reserved for real Playwright captures (gap)
├── deck/
│   ├── slides-src/               # 13 HTML slide templates + theme.css
│   ├── slides/                   # rendered PNGs (1920×1080)
│   ├── slides.pdf                # img2pdf assembly of the PNGs
│   ├── render.mjs                # Playwright slide+mock renderer
│   ├── capture-flutter.mjs       # best-effort Flutter web capture
│   └── build-pdf.sh              # PNG → PDF
├── music/
│   └── README.md                 # licence notes; track is generated in build
├── video/
│   ├── captions.json             # per-slide duration + caption
│   ├── build-video.sh            # ffmpeg slideshow compositor
│   └── out/sona-demo.mp4         # 1920×1080, 30 fps, 92.2 s
└── README.md                     # this file
```

## Licence summary

| Asset | Source | Licence |
|---|---|---|

| `screenshots/flutter/launcher.png` | Real screenshot of `apps/sona` running locally | © Sona — internal use |
| `deck/slides-src/*.html`, `theme.css` | Hand-authored in this repo | CC0 / own work |
| `deck/slides/*.png`, `slides.pdf` | Rendered from above via Playwright + img2pdf | CC0 / own work |
| `video/out/sona-demo.mp4` background pad | Generated by `ffmpeg` sine synthesis at build time | CC0 / own work |
| Fonts used in video burn-in (Inter, DejaVu Sans) | System fonts | Inter: SIL OFL 1.1; DejaVu: free Bitstream Vera derivative |
| Personas | `scripts/personas/*.json` (synthetic) | Internal — not real PHI |

**To drop in a real royalty-free track** (e.g. Pixabay Music CC0, Free
Music Archive CC-BY, YouTube Audio Library), place the file at
`music/<name>.mp3` and update `video/build-video.sh` to use
`-i music/<name>.mp3` instead of the synthesized pad. Record the
attribution in `music/README.md`.

## Rebuild

```bash
# 1. render slides + mocks → PNGs
node assets/marketing/deck/render.mjs

# 2. assemble the PDF
assets/marketing/deck/build-pdf.sh

# 3. build the demo video (uses PNGs from step 1 + synthesized audio)
assets/marketing/video/build-video.sh
```
