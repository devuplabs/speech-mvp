## Alternate track — "Heartwarming" by Kevin MacLeod

`assets/marketing/music/kevin-macleod-heartwarming.mp3` is kept as a
warm, more uplifting alternative for runs where a friendlier-sounding
score is preferred over the contemplative default. Same CC BY 4.0
licence. Track length 72 s, so it will loop once across a 92-s render —
the loop point is roughly inaudible thanks to the slow tempo and
`-stream_loop -1` in `build-video.sh`.

To swap:

```bash
MUSIC=$(pwd)/assets/marketing/music/kevin-macleod-heartwarming.mp3 \
  assets/marketing/video/build-video.sh
```

## CC0 fallback — generated ambient pad

If neither MP3 is present and no `MUSIC=...` is exported, the build
script falls back to a CC0 ambient pad generated by ffmpeg sine
synthesis (two stacked low sines, heavy low-pass, ~10 % volume).
This was the initial draft of the demo video; honest feedback was that
it sounded like a drone rather than music, so it is now only used as a
safety net when offline.
